# Advent of Code 2025

My solutions to the advent of code 2025 puzzles.
Solutions are written in Golang to familiarize myself with the basics of the language.

To run a specific day/part solution, run:

```bash
go run main.go <day> <part>
```

Or just run an interactive mode to pick a day and part from the TUI:

```bash
go run main.go
```
